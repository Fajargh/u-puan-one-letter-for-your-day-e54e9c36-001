# One Letter for Your Day — Q for quitting

One letter, and nothing else. The program writes the single letter `Q` to
`/output/entry.txt`, where the make.fun judge reads it two at a time and
picks the letter whose hidden word feels more vivid, funnier or more true.

The word behind the letter is **quitting**. The day felt like quitting
everything — the emails, the meetings, the whole to-do list. Q is a sharp,
unmistakable initial for it: almost no other day-word starts with Q, so the
letter lands as one honest report instead of a vague mood.

## Run it

```sh
python3 main.py
```

This writes exactly one byte, the letter `Q` with no newline, to
`/output/entry.txt` and prints it.
